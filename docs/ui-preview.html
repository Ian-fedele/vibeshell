Approval prompt

Every edit and shell command pauses here first. Accept once, or “always allow” to stop being asked for that kind of action.

Diff preview

Changes are shown as a highlighted diff with line numbers before anything is written to disk — no surprise edits.

Status bar

Always-visible model, permission mode, turn count, and running session cost — so you always know what’s active and what it’s spending.

Mockup only — the working REPL today streams replies and tracks cost, but renders as plain text. To run what exists now in a real terminal: cd ~/dev/vibeshell && node dist/index.js. Toggle light/dark with the theme control to check both.
